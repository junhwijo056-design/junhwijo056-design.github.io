# 조준휘 자기소개

소개, 프로젝트, 강점, 진로 목표를 담은 반응형 정적 웹사이트입니다.

## 웹사이트

[https://junhwijo056-design.github.io/](https://junhwijo056-design.github.io/)

## 소개

- **이름:** 조준휘
- **학력:** 가천대학교 경영학과 3학년 재학 중
- **목표:** AI 솔루션 분야 취업과 창업
- **강점:** 추진력, 끈기, 기복이 적은 꾸준한 태도

## 프로젝트

- **AI Native Startup:** AI-native의 의미를 정의하고 스타트업을 분석해 VC에 투자를 제안하는 프로젝트
- **Replica system:** Codex를 활용한 바이브코딩 방식의 시스템 구현

## 주요 기능

- 소개와 프로젝트 내용 검색
- 다크 모드 / 라이트 모드 전환 및 테마 저장
- 모바일과 데스크톱에 대응하는 반응형 디자인

## 실행

저장소를 다운로드한 후 `index.html`을 브라우저에서 열면 됩니다.
로컬 서버로 확인하려면 이 파일이 있는 폴더에서 다음 명령을 실행합니다.

```powershell
py -m http.server 4173 --bind 127.0.0.1
```

브라우저에서 [http://127.0.0.1:4173/](http://127.0.0.1:4173/)에 접속합니다.

## 배포

GitHub Pages에서 `main` 브랜치의 루트(`/`)를 배포합니다.

CSS와 JavaScript는 `index.html` 안에 포함되어 있습니다. 웹사이트 내용을 수정하려면 `index.html`을 수정하고 커밋하면 됩니다. GitHub Pages 배포가 완료되면 공개 사이트에 반영됩니다.

설정 위치: **Settings → Pages → Deploy from a branch → main / (root)**
